# Files added to the game folder

Remove these to restore vanilla. No game file is modified.

| File | Purpose |
|---|---|
| `version.dll` | Mod loader and client. Loaded with `WINEDLLOVERRIDES=version=n,b` |
| `lia_ap.log` | Client log, written at runtime |
| `lia_ap.cfg` | Saved connection fields, written on Connect |

Outside the game folder: `AppData/LocalLow/Eternity/Leaf it Alone/AP/` holds per-seed saves and state.
